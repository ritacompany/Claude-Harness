# Option sets

Any ask for options, alternatives, versions, directions or "show me a few".

## How many and how different

- No number given means three; a number given means exactly that many; an ask for options is never
  answered with one recommendation. (E0004, E0185, E0224, E0267)
- Deliver every option, state, tab and combination he named, including a combined version Claude
  itself suggested; tick them off before sending. (E0124, E0436, E0481, E0554)
- When he is unsure between two approaches, or Claude names two, build both side by side instead
  of asking which. (E0147, E0271, E0300)
- Each option is a different structure or direction, not the same layout with one element moved or
  a colour swapped; if two look alike, redo one before he sees them. (E0170, E0200, E0215, E0216)
- Make them creative and memorable, never timid or generic, and never a reworded last round.
  (E0001, E0006, E0014, E0046)
- Each option solves the stated problem the way a product designer would defend; no decorative
  gimmicks. (E0272, E0281, E0302)
- Ground the set in three or more real products or patterns that fit the same kind of page, cited.
  References give style; the layout comes from the task. (E0483, E0751, E1329, E0576, E1522)

## How they are shown

- Design options (screens, pages, sections, styles) go on a design canvas he can open, comment on
  and edit, with his pick then built in Figma. (E1423, E1444, E1462, E1492)
- Options that are not drawn on a canvas (copy, approaches, a page of alternatives) go on one page
  with a small tab bar across the very top, outside the design: one tab per option, a click swaps
  the whole design. (E0007, E0041, E0086, E0087)
- Many small variants of one element (10, 15, 30) go spaced on one scrolling sheet with no tabs.
  (E0229, E0866, E0936, E1831)
- Each option shows the whole page it lives on, at real size, with real neighbours; never a crop of
  the one element. (E0220, E0359, E0435, E0439)
- Hold everything constant except the thing under test. (E0959, E1447, E1519)
- When the options are rules or styles, show each applied to several real examples in a grid so
  the set compares side by side. (E0803, E1821, E1951)
- An option that spans screens is a clickable flow inside its tab with a clear starting point.
  (E0068, E0124, E0125, E0284)
- An interaction or animation is built working so he can feel it, every state reachable.
  (E0200, E0219, E0228)
- Letter the options A, B, C; numbers stay free for sections and steps. (E0981, E1954)
- A short bulleted why sits beside each option (how it works, user impact, risks, what changed),
  never drawn on top of the design, and it claims nothing the design does not show.
  (E0230, E0280, E0361, E0962, E0964)

## Fidelity and rounds

- First round layout options are mid fidelity (real hierarchy and spacing, neutral colour); canvas
  examples he asks to see finished get as close to finished as possible. (E0549, E0890, E1128, E1979)
- Start from his latest design and keep what he already settled; push a reference further rather
  than copying it. (E0125, E0536, E0602, E0722)
- When he corrects one option, apply the fix to every option and branch before he looks again.
  (E1414, E1834, E1970)
- The next round builds from his pick, keeps what he liked and stops redoing what he marked solved.
  (E0185, E0209, E1328, E1828)
- Before a big build, a quick flat image of each direction lets him pick first. (E0256, E1089, E1097)
