# Editors, tuners, playgrounds and labs

Any tool where he adjusts something live: type and style tuners, effect and motion tuners, number
or token pickers, style labs, playgrounds, mixers.

## Shell

- The preview fills the main area and holds only the output; controls live in a right sidebar he
  can drag wider and collapse; side panels stay put while the preview scrolls on its own; a layers
  style left panel appears when there are parts to pick. He never scrolls to reach a control.
  (E1119, E1129, E1448, E1638, E1818)
- Controls are grouped in collapsible categories. (E1118, E1132, E1646)
- Dark neutral chrome with no accent colour; subtle fills that never read as a button.
  (E1127, E1585, E1587, E1891)

## Controls

- Pick each control for its property: sliders only where they help, number fields that work like
  Figma's (type a value or drag to scrub, arrow keys to step), pickers that preview each option and
  enough range for someone with no animation background. (E0476, E1118, E1121, E1448)
- Every control visibly changes the whole subject, is labelled so he knows which way it goes and
  is left out if it does nothing. (E1427, E1450, E1451, E1637)
- He can steer the preview: zoom, change colours on every variant, swap in his own image or logo,
  step back and forward. (E1449, E1637, E1647, E1658)
- A before and after (or base against tuned) sits side by side, and results show across the whole
  set in real context. (E1085, E1640, E1795, E1806)
- A tool with steps lets him lock the current choices, move on with a small Next and always go
  back without losing work. (E1125, E1126, E1131, E1647)
- Colour values show and accept hex. (E0122)

## Content and start point

- A playground starts from the current version of his real page, ready to drop in outside
  components and effects to try them in place. (E1727, E1728, E1782, E1789)
- Test with his real copy in a spread of lengths and sizes. (E0828, E1818)
- A recreation from a recording copies every behaviour exactly and adds only the extras he names.
  (E1643, E1645, E1653)
- Anything he has to feel (a button effect, a hover, an animated background) arrives as a live
  build with a tuner by default, never a video of it. (E1117, E1590, E1594, E1891)

## Saving and hand back

- Autosave, survive a reload, export the exact values he settled on, one obvious way to send his
  changes back, and the tool kept where he can reopen it later. (E0413, E1657, E1777, E1813)
- Before calling it done, push every slider to both ends, compare with the reference and check it
  at phone and desktop width with saving included. (E1644, E1648, E1652, E1823)
