# Dashboards, trackers and status pages

- Counts and totals show up front without filtering or digging; track only what serves the stated
  goal; never chart what a number already shows; keep it uncluttered. (E1141, E1142, E1143, E1144, E1145)
- Show what is done and what is left at a glance, with a legend for every status colour or icon,
  and status marks clearer than coloured dots. (E1505, E1919, E1920, E1700, E1922, E2950)
- A live dashboard refreshes itself when the data changes and opens an item in the same tab.
  (E1715, E1699, E1713, E2805)
- Group items the way he already groups them. (E1711)
- Use realistic volumes of real data. (E0760, E1707)
- Visuals look crafted and current and follow the references he points to. (E1690, E1692, E1695)
- Word labels so nobody is made to feel performance managed. (E1151)
