# Where to search

Step 3 of the procedure: use at least three independent sources that index the type you need, with
two or three phrasings each. Every link below was checked on 18 Nov 2026 (GitHub ones with
`git ls-remote`, because some networks refuse GitHub's web pages).

## In product (a first stop, never the survey)

- `SearchSkills`, `SearchPlugins`, `SearchMcpRegistry` and `ListSkills`: the user's account, their
  org catalogue and Anthropic's marketplaces.
- The `/plugin` Discover tab in Claude Code.

## Skills

- https://skills.sh: a directory of agent skills with install counts.
- https://claudemarketplaces.com: plugin marketplaces and the skills inside them.
- https://github.com/anthropics/skills: Anthropic's own skills, useful as a structure reference.
- https://github.com/travisvn/awesome-claude-skills and
  https://github.com/ComposioHQ/awesome-claude-skills: curated lists; check each entry's repo, not the
  list's blurb.

## Plugins, commands, hooks and agents

- https://github.com/anthropics/claude-plugins-official: Anthropic's plugin directory.
- https://github.com/hesreallyhim/awesome-claude-code: a curated list by category (hooks, linting,
  slash commands, workflows).
- https://www.aitmpl.com and https://github.com/davila7/claude-code-templates: templates for agents,
  commands, hooks and settings.

## MCP servers

- https://registry.modelcontextprotocol.io: the official MCP registry.
- https://smithery.ai: a hosted MCP directory with usage figures.

## Command line tools and libraries

- https://www.npmjs.com and https://pypi.org: search by job; monthly downloads are a usage signal.

## What people report

- https://hn.algolia.com: Hacker News search; try "Show HN" plus the job.
- https://forum.cursor.com: rules and context tooling that often transfers to Claude Code.
- Reddit (r/ClaudeAI, r/ClaudeCode): often refuses automated reads; reach it through a web search.

## Signals to collect for each finalist

Stars or installs, the date of the last commit to the candidate's own folder (read from git), the
maintainer, open issues and whether it ships scripts, hooks or network calls. Then read its files:
listing text and stars never decide a pick.
