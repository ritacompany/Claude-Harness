1. The CSS mask-image property sets the image used as the mask layer for an element, hiding sections of the element. | https://developer.mozilla.org/en-US/docs/Web/CSS/mask-image
2. A mask-image value can be any type of image, including generated images such as CSS gradients. | https://developer.mozilla.org/en-US/docs/Web/CSS/mask-image
3. MDN states that element areas masked by opaque sections of the mask-image are rendered, while areas masked by transparent sections are hidden. | https://developer.mozilla.org/en-US/docs/Web/CSS/mask-image
4. When mask-mode is or resolves to alpha, only the alpha channel of the mask's colours matters, not hue or lightness. | https://developer.mozilla.org/en-US/docs/Web/CSS/mask-image
5. The default mask-mode is match-source, and an image mask (other than an SVG mask element) is generally treated as alpha. | https://developer.mozilla.org/en-US/docs/Web/CSS/mask-image
6. MDN lists mask-image as Baseline widely available, "available across browsers since December 2023". | https://developer.mozilla.org/en-US/docs/Web/CSS/mask-image
